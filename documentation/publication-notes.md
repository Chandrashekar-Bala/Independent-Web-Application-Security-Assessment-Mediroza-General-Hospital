# Publication Notes

## Public repository

Do not publish:

- recovered patient-report passwords
- patient PDFs
- raw password hashes
- the internal HR/shareholder SQL dump
- active session cookies
- unredacted screenshots containing sensitive information
- confidential source archives containing those artifacts

Use the portfolio-safe case study for public presentation.

## Private repository

The complete evidence master may be retained in a private repository for provenance and interview demonstration. Access should be limited to authorized reviewers.
